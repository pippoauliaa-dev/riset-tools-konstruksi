# Riset Celah Tools Industri Konstruksi Indonesia

Desk research untuk menemukan masalah operasional di industri konstruksi Indonesia yang berpotensi dipermudah dengan tools digital.

## Kesimpulan utama

Celah terbesar bukan pada ketiadaan software konstruksi secara umum, melainkan pada putusnya aliran informasi antara:

- kondisi lapangan;
- progress pekerjaan;
- biaya aktual;
- material;
- perubahan pekerjaan;
- subkontraktor; dan
- penagihan.

Peluang produk paling menjanjikan adalah **Project Margin Control untuk kontraktor spesialis**: tools ringan yang menghubungkan RAB, progress lapangan, biaya aktual, pekerjaan tambah, dan bukti penagihan agar margin proyek tidak bocor tanpa diketahui.

## Prioritas peluang

1. **RAB-to-actual cost control** — membandingkan anggaran, progress, biaya aktual, dan forecast.
2. **Variation order & claim evidence** — mendokumentasikan perubahan pekerjaan agar dapat diverifikasi dan ditagihkan.
3. **Material request-to-delivery** — menghubungkan kebutuhan pekerjaan, pembelian, penerimaan, dan penggunaan material.
4. **Subcontractor progress & payment reconciliation** — mencocokkan progress, opname, invoice, retensi, dan pembayaran.
5. **Daily site evidence** — mengubah laporan harian, foto, kendala, dan progress menjadi bukti terstruktur.
